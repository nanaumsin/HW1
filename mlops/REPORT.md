# 모델 업데이트 리포트

## 데이터
- 출처: Hugging Face `e9t/nsmc` (네이버 영화 리뷰, **CC-BY-2.0**), test split 원본 `github.com/e9t/nsmc`
- 고정 seed `20261109`로 긍정 50 / 부정 50, 총 100건 추출
- **튜닝 30건** (15/15): 오류 분석, 임계값 탐색, 모델 선택에만 사용
- **최종 평가 70건** (35/35): 튜닝·선택에 사용하지 않고 마지막 비교에만 1회 사용
- 재현: `python mlops/prepare_data.py` → `python mlops/evaluate.py ...` (데이터·결과 파일은 커밋 제외)

## 지표
이진 정확도(긍정/부정 라벨 기준, "중립" 예측은 오답 처리), Macro-F1, 중립 판정 비율

## 기존 모델 오류 분석 (튜닝 30건, 오류 13건)
- 중립(3 stars) 판정 7건(54%): "감동적이야", "멤버들 하나하나 다 좋움"처럼 감정이 분명한 짧은 한국어 리뷰를 애매하게 처리
- 극성 반대 6건: "눈물이 난다/울어본 적은 처음"(감동) 같은 한국어 정서 표현과 띄어쓰기 없는 구어를 오해
- 원인: nlptown 모델은 en/nl/de/fr/es/it 리뷰로 학습되어 한국어 지식이 부족함 + argmax 별점 3을 무조건 중립 처리

## 개선 시도 (2회)
| | 내용 | 튜닝 정확도 |
|---|---|---|
| 기존 | nlptown, argmax 별점 | 0.567 |
| 시도 1 | 전처리(반복 문자·공백 정규화) + 5개 별점 확률의 기대값으로 판정(임계값 3.0, 튜닝셋 grid search) | 0.767 |
| **시도 2 (채택)** | 시도 1 + 한국어 입력은 사전학습 한국어 감성 모델 `Copycats/koelectra-base-v3-generalized-sentiment-analysis`(Apache-2.0)로 라우팅, 그 외 언어는 기존 다국어 모델 유지 | **0.933** |
